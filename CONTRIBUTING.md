# Contributing to Sanjaykumar M — Portfolio

Thank you for your interest in contributing! This is a personal portfolio project, but contributions for bug fixes, accessibility improvements, and performance enhancements are welcome.

## How to Contribute

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/your-improvement`)
3. **Commit** your changes (`git commit -m "Add: brief description"`)
4. **Push** to the branch (`git push origin feature/your-improvement`)
5. **Open** a Pull Request

## Guidelines

- Maintain the existing design system and color palette
- Ensure responsive behavior across all breakpoints (320px–1920px)
- Test accessibility with a screen reader or browser devtools
- Do not commit environment files, API keys, or personal data
- Use semantic HTML where possible
- Keep CSS organized within the existing section structure

## Reporting Issues

Use the GitHub Issues tab to report bugs or request features. Please include:

- Browser and OS version
- Steps to reproduce (if applicable)
- Screenshots (if UI-related)

## Code Style

- **HTML**: Semantic elements, proper indentation (4 spaces)
- **CSS**: BEM-like naming, organized by section number
- **JavaScript**: Vanilla JS, ES6+ syntax, clear comments
